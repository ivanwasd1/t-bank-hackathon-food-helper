# FoodHelper — планировщик меню и покупок

Командный проект для хакатона Т-Банка в Минске. FoodHelper помогает подбирать рецепты, планировать меню, учитывать продукты в холодильнике и автоматически составлять список покупок.

## Результат и моя роль

Команда заняла **3-е место**.

В команде я отвечал за развитие продуктовой концепции, подготовку презентации, структуру выступления и работу над питчем проекта.

## Возможности

- настройка профиля и пищевых предпочтений;
- каталог готовых рецептов;
- рекомендации с учётом предпочтений пользователя;
- избранные рецепты;
- планирование меню на день и неделю;
- учёт продуктов в холодильнике;
- анализ фотографии продуктов через Gemini API;
- автоматическое формирование списка покупок.

## Архитектура

```text
T-Bank-Hakaton
```

Backend предоставляет REST API для пользователей, рецептов, избранного, меню, холодильника и списков покупок. Frontend обращается к нему через HTTP и хранит пользовательский сценарий в React-приложении.

## Быстрый запуск

Необходимы Python 3.8+, Node.js 16+ и собственный Gemini API key.

1. Создайте `.env` из шаблона `.env.example` и укажите ключ:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   PORT=5000
   DEBUG=False
   ```

2. Установите и запустите backend:

   ```bash
   python -m pip install -r requirements.txt
   python init_db.py
   python app_backend.py
   ```

3. В отдельном терминале установите и запустите frontend:

   ```bash
   cd frontend
   npm install
   npm start
   ```

4. Откройте `http://localhost:3001`.

Подробная инструкция и типовые проблемы описаны в [QUICK_START.md](QUICK_START.md) и [SETUP.md](SETUP.md).

> Доступность AI-функций зависит от доступности Gemini API в регионе и лимитов используемого ключа. Остальные части приложения запускаются локально.

## Основные API-маршруты

- `POST /api/users` — создать пользователя;
- `GET /api/recipes` — получить каталог рецептов;
- `GET /api/users/:id/recipes/recommendations` — получить рекомендации;
- `POST /api/menus/generate` — сформировать меню;
- `POST /api/analyze` — распознать продукты на фотографии;
- `POST /api/users/:id/shopping-lists/generate` — сформировать список покупок.

# 🚀 Быстрый запуск FoodHelper

## Вариант 1: Автоматический запуск (рекомендуется)

Просто запустите файл:
```
start_all.bat
```

Этот скрипт автоматически:
- ✅ Проверит наличие Python и Node.js
- ✅ Инициализирует базу данных (если нужно)
- ✅ Запустит backend и frontend в отдельных окнах

## Вариант 2: Ручной запуск

### Шаг 1: Подготовка

1. **Создайте файл `.env`** в корневой папке:
   ```
   GEMINI_API_KEY=ваш_api_ключ_здесь
   ```

2. **Установите зависимости backend:**
   ```bash
   py -m pip install -r requirements.txt
   ```

3. **Инициализируйте базу данных:**
   ```bash
   py init_db.py
   ```

4. **Установите зависимости frontend:**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

### Шаг 2: Запуск

**В первом терминале (Backend):**
```bash
py app_backend.py
```

**Во втором терминале (Frontend):**
```bash
cd frontend
npm start
```

## 📍 Адреса

После запуска:
- **Backend API:** http://localhost:5000
- **Frontend:** http://localhost:3001
- **API Health Check:** http://localhost:5000/api/health

## ⚠️ Важно

1. **GEMINI_API_KEY** - обязателен для работы AI-функций (сканирование фото)
2. Оба сервера должны быть запущены одновременно
3. Backend должен запуститься первым (frontend ждет его)

## 🔧 Решение проблем

### Python не найден
- Установите Python 3.8+ с https://python.org
- Убедитесь, что Python добавлен в PATH

### Node.js не найден
- Установите Node.js 16+ с https://nodejs.org
- Перезапустите терминал после установки

### Ошибка порта занят
- Закройте другие приложения на портах 3000 и 5000
- Или измените порты в настройках

### Ошибка 429 (Gemini API)
- Проверьте лимиты вашего API ключа
- Подождите несколько минут
- Используйте модель gemini-1.5-flash (уже настроена)
